Datenschutz

Die Abo-Übersicht ist ein privates Hobby-Projekt für den persönlichen Gebrauch. Sie zeigt dem Betreiber eine Übersicht neuer Videos seiner eigenen YouTube-Abos. Sie wird nicht für andere Personen angeboten.

Zugriff auf das Google-Konto

Die Anwendung nutzt ausschließlich Lesezugriff auf YouTube (Berechtigung youtube.readonly), um die Liste der abonnierten Kanäle und die Länge neuer Videos abzurufen. Sie kann nichts im Konto ändern, nichts veröffentlichen und keine E-Mails oder anderen Google-Daten lesen. Den Zugriff kannst du jederzeit unter myaccount.google.com/permissions widerrufen.

Welche Daten verarbeitet werden

  • Liste der abonnierten Kanäle sowie Titel, Beschreibung, Vorschaubild, Datum und Länge neuer Videos dieser Kanäle.
  • Titel und Beschreibungen werden zur Erstellung von Themen und Kurz-Zusammenfassungen an die Claude-API von Anthropic übermittelt.
  • Das Ergebnis wird als Datei auf GitHub Pages gespeichert und täglich neu erstellt. Zusammenfassungen werden nur für den angezeigten Zeitraum (höchstens 7 Tage) aufbewahrt.

Beim Aufruf der Seite

Es gibt kein Tracking, keine Analyse und keine Cookies. Beim Aufruf werden Inhalte von folgenden Diensten geladen, die dabei technisch bedingt die IP-Adresse erhalten: GitHub Pages (Hosting), Google Fonts (Schriftart) und YouTube (Vorschaubilder).

Weitergabe

Daten werden nicht verkauft und an niemanden außer den oben genannten Diensten weitergegeben. Die Nutzung von Daten aus Google-APIs entspricht der Google API Services User Data Policy.
